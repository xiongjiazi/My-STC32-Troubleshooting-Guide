## 项目概述

本项目是一套基于 **STC32G12K128 微控制器**开发的工厂货运机器人原型机。

该项目主要用于学习和实践嵌入式硬件系统开发流程，涵盖主控系统、电机驱动、传感器采集以及外围功能电路设计。项目开发过程中重点关注硬件系统的稳定性、模块之间的协同工作以及实际调试过程中的问题分析。
项目的电路原理图绘制、PCB绘制以及成品打样均在嘉立创EDA完成。嘉立创EDA导出的eprj文件`工厂货运机器人原型机_第一版.eprj2`包含有电路原理图以及PCB设计。

当前版本集成的主要功能模块包括：

- **STC32G12K128 主控系统**
- **四路电机驱动系统**
- **红外循迹检测模块**
- **超声波距离检测模块**
- **蜂鸣器状态提示电路**
- **白色 LED 照明电路**
- **ADC 电压检测电路**


在项目开发过程中，主要围绕以下工程内容展开：

- 电源供电电路设计与功能验证；
- MCU 外围电路设计与模块集成；
- 电机驱动电路调试与运行测试；
- 传感器信号采集与功能验证；
- 硬件异常问题定位与优化。


本仓库记录该工厂货运机器人原型机从硬件设计、模块调试到功能验证过程中的相关内容，包括：

- 电路设计思路；
- 元器件选型记录；
- PCB 设计注意事项；
- 硬件调试过程；
- 问题分析与解决方案；
- 后续版本功能扩展规划。

## 系统架构

本项目整体采用模块化设计，主要由电源管理模块、主控模块、驱动模块、传感器模块以及外围功能模块组成。

系统通过电源模块为各功能单元提供稳定供电，STC32G12K128作为核心控制单元，负责传感器数据采集、外设控制以及电机运动控制。


### 1. 主控模块

系统核心控制器采用 STC32G12K128 微控制器。

主要负责：

- GPIO 外设控制；
- PWM 信号输出；
- ADC 电压采集；
- 传感器数据读取；
- 外围模块状态控制。


### 2. 电机驱动模块

系统采用四电机驱动结构，通过电机驱动电路实现移动平台运动控制。

当前已完成：

- 电机驱动功能测试；
- PWM 调速实验。


### 3. 传感器采集模块

系统集成多种传感器接口，用于获取外部环境及系统状态信息。

包括：

- 红外循迹模块；
- 超声波距离检测模块；
- ADC 电压检测模块。


### 4. 外围功能模块

系统增加辅助功能电路，用于状态显示及交互：

- 蜂鸣器报警；
- LED 照明。


针对部分尚未完成的功能，例如超声波避障模块，
后续将通过实际测试验证传感器兼容性、
信号稳定性以及控制算法实现。


## 硬件设计

本项目硬件系统围绕 STC32G12K128 微控制器展开设计，
主要由主控模块、电源模块、电机驱动模块、传感器接口模块以及外围功能电路组成。

硬件设计过程中重点考虑系统供电稳定性、模块兼容性以及后期功能扩展需求。


---

## 1. 主控模块

系统采用 STC32G12K128 作为核心控制器。

MCU主要负责：

- 外部传感器信号采集；
- PWM 信号输出；
- 电机控制；
- ADC 数据采集；
- 外围设备控制。


通过 MCU 对各功能模块进行统一管理，实现工厂货运机器人原型机的基础控制。


---

## 2. 电源管理模块

电源部分负责为系统各模块提供稳定工作电压。

设计内容包括：

- 主电源输入；
- 电压转换；
- MCU及外围模块供电；
- 电源状态检测。

在硬件调试过程中，通过 ADC 电压检测电路对系统供电状态进行监测，用于辅助判断电源稳定性。

主电源模块采用2节14500圆柱形锂离子电芯串联供电，单体额定电压3.7V、额定容量800mAh，串联后输入电压7.2V；后端采用L7805CV线性稳压器（TO-220封装，最大耐压35V，额定输出5V/1.5A）实现电压稳压。主控MCU选用STC32G12K128，芯片VCC引脚由稳压器输出5V电源供电，同时该5V电源网络为蜂鸣器、红外循迹模块、超声波避障电路、车灯负载等外设电路统一供电。
补充：L7805为线性稳压，7.2V转5V存在压差功耗，持续大负载需预留散热空间；这边采用的是散热片15.5*10.5*24 带针 H型进行散热，存在较大空间改良；14500锂电充满电压单节4.2V，串联最高输入8.4V，低于芯片35V耐压，满足器件规格；若外设瞬时电流较大，建议在各路外设电源入口增设滤波电容。

## 3. 电机驱动模块

电机驱动模块采用RZ7899驱动芯片，负载选用N20减速电机，电机额定工作电压5V，减速比1:240，配套车轮周长15mm。

当前已完成：

- 电机驱动电路连接；
- PWM 调速实验；
- 电机运行测试。


MCU输出 PWM 控制信号，通过驱动电路实现电机速度调节。

## PCB设计注意事项

本项目 PCB 基于嘉立创EDA完成设计，主要围绕移动机器人控制系统的功能需求进行硬件布局与走线规划。
PCB设计过程中重点考虑电源稳定性、信号完整性、模块扩展以及后期调试便利性。


### 1. 电源设计

由于系统同时包含 MCU 控制部分、电机驱动部分以及多个传感器模块，电源部分需要兼顾稳定供电和负载变化带来的影响。

设计过程中主要考虑：

- 区分控制电路与驱动电路供电路径；
- 合理规划电源走线；
- 增加必要的滤波与去耦措施；
- 为后续系统调试提供电压检测接口。


### 2. 元件布局规划

PCB布局根据不同功能模块进行区域划分：

- MCU最小系统区域；
- 电机驱动区域；
- 电源管理区域；
- 传感器接口区域；
- 外围功能电路区域。


通过模块化布局，提高电路可读性，同时方便后期硬件调试和故障定位。


### 3. 电机驱动与信号隔离

由于电机运行过程中会产生电流变化和电磁干扰，PCB设计时对电机驱动部分进行了独立规划。

主要考虑：

- 驱动部分与控制部分合理分区；
- 优化电机供电路径；
- 减少大电流回路对 MCU 和传感器信号的影响。


### 4. 调试接口设计

为了方便开发阶段进行测试，PCB预留部分调试接口：

- MCU程序下载接口；
- 串口通信接口；
- 电压检测接口；
- 外部传感器接口。


这些接口用于功能验证、参数测试以及问题定位。


### 5. 后续优化方向

当前版本 PCB 主要完成基础功能验证，后续版本将根据实际运行情况进一步优化：

- 电源抗干扰设计；
- 信号完整性优化；
- 接口保护设计；
- PCB布局细节优化。
