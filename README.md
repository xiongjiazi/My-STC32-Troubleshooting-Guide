# STC32 Multifunctional Line Tracking Robot

A small mobile robot based on STC32G12K128 MCU.

This project includes mechanical structure design,
custom PCB development, motor control,
sensor integration and hardware debugging.

The purpose of this project is to explore the complete
development workflow of an embedded robotic system,
from component selection to final assembly and testing.


## Features

- Line tracking
- Obstacle avoidance
- Four motor drive system
- Battery voltage monitoring
- Custom PCB hardware
- Hardware debugging records


## Hardware Architecture

Controller:
- STC32G12K128

Motor Driver:
- RZ7899 H-Bridge Driver

Sensors:
- Infrared tracking module
- Ultrasonic sensor
- ADC battery detection
