## 项目概述

本项目是一套基于 **STC32G12K128 微控制器**开发的工厂货运机器人原型机。

该项目主要用于学习和实践嵌入式硬件系统开发流程，涵盖主控系统、电机驱动、传感器采集以及外围功能电路设计。项目开发过程中重点关注硬件系统的稳定性、模块之间的协同工作以及实际调试过程中的问题分析。
项目的电路原理图绘制、PCB绘制以及成品打样均在嘉立创EDA完成。嘉立创EDA导出的eprj文件`工厂货运机器人原型机_第一版.eprj2`包含有电路原理图以及PCB设计。

当前版本集成的主要功能模块包括：

- **STC32G12K128 主控系统**
- **四路电机驱动系统**
- **红外循迹检测模块**
- **超声波距离检测模块**
- **蜂鸣器状态提示电路**
- **白色 LED 照明电路**
- **ADC 电压检测电路**


在项目开发过程中，主要围绕以下工程内容展开：

- 电源供电电路设计与功能验证；
- MCU 外围电路设计与模块集成；
- 电机驱动电路调试与运行测试；
- 传感器信号采集与功能验证；
- 硬件异常问题定位与优化。


本仓库记录该工厂货运机器人原型机从硬件设计、模块调试到功能验证过程中的相关内容，包括：

- 电路设计思路；
- 元器件选型记录；
- PCB 设计注意事项；
- 硬件调试过程；
- 问题分析与解决方案；
- 后续版本功能扩展规划。

## 2. 电源管理模块

电源部分负责为系统各模块提供稳定工作电压。

设计内容包括：

- 主电源输入；
- 电压转换；
- MCU及外围模块供电；
- 电源状态检测。

在硬件调试过程中，通过 ADC 电压检测电路对系统供电状态进行监测，用于辅助判断电源稳定性。

主电源模块采用2节14500圆柱形锂离子电芯串联供电，单体额定电压3.7V、额定容量800mAh，串联后输入电压7.2V；后端采用L7805CV线性稳压器（TO-220封装，最大耐压35V，额定输出5V/1.5A）实现电压稳压。主控MCU选用STC32G12K128，芯片VCC引脚由稳压器输出5V电源供电，同时该5V电源网络为蜂鸣器、红外循迹模块、超声波避障电路、车灯负载等外设电路统一供电。
补充：L7805为线性稳压，7.2V转5V存在压差功耗，持续大负载需预留散热空间；这边采用的是散热片15.5*10.5*24 带针 H型进行散热，存在较大空间改良；14500锂电充满电压单节4.2V，串联最高输入8.4V，低于芯片35V耐压，满足器件规格；若外设瞬时电流较大，建议在各路外设电源入口增设滤波电容。

### 1. 电源设计

由于系统同时包含 MCU 控制部分、电机驱动部分以及多个传感器模块，电源部分需要兼顾稳定供电和负载变化带来的影响。

设计过程中主要考虑：

- 区分电源线实际符合要求的口径大小；
- 区分控制电路与驱动电路供电路径；
- 合理规划电源走线；
- 增加必要的滤波与去耦措施；
- 为后续系统调试提供电压检测接口。


### 2. 元件布局规划

PCB布局根据不同功能模块进行区域划分：

- MCU最小系统区域；
- 电机驱动区域；
- 电源管理区域；
- 传感器接口区域；
- 外围功能电路区域。


通过模块化布局，提高电路可读性，同时方便后期硬件调试和故障定位。


### 3. 电机驱动与信号隔离

由于电机运行过程中会产生电流变化和电磁干扰，PCB设计时对电机驱动部分进行了独立规划。

主要考虑：

- 驱动部分与控制部分合理分区；
- 优化电机供电路径；
- 减少大电流回路对 MCU 和传感器信号的影响。


### 4. 调试接口设计

为了方便开发阶段进行测试，PCB预留部分调试接口：

- MCU程序下载接口；
- 串口通信接口；
- 电压检测接口；
- 外部传感器接口。


这些接口用于功能验证、参数测试以及问题定位。


### 5. 后续优化方向

当前版本 PCB 主要完成基础功能验证，后续版本将根据实际运行情况进一步优化：

- 电源抗干扰设计；
- 信号完整性优化；
- 接口保护设计；
- PCB布局细节优化。

## 调试案例：RZ7899电机驱动电路调试
### 1. 模块基础信息
- 驱动芯片：RZ7899 贴片封装
- 执行器件：四路N20 5V减速电机，减速比1:240
- 主控：STC32G12K128，通过定时器PWM输出控制驱动
- PCB硬件版本：53*23mm主控底板
- 供电方案：7.4V锂电 → L7805CV稳压5V为驱动与MCU供电
- 硬件连接方式：PCB焊盘引出排母拓展接口，电机金属触点直插排母

### 2. 调试前置条件
1. PCB完成焊接，静态万用表预检无短路、断路；
2. 底层固件完成GPIO、PWM驱动封装（HAL层电机驱动接口可用）；
3. 测试工具：数字万用表、串口调试助手、备用空白PCB、电烙铁、固定支架；
4. PCB设计规范约束：驱动电源线宽40mil，ADC检测走线与电机功率线路物理隔离，全域铺铜+线性缝合孔完整接地。

### 3. 分步调试操作流程
#### 3.1 静态不通电预检
1. 目视检查RZ7899贴片所有引脚，排查少锡、连锡、偏移虚焊；
2. 万用表通断档测量驱动电源、四路电机输出引脚，确认无对地/对电源短路；
3. 核对排母与RZ7899输出引脚导通一致性，确认线路无断连。


#### 3.2 空载上电硬件电气测试
1. 接入锂电供电，测量L7805输出稳定5V，RZ7899供电引脚电压正常；（以下时测量图）
2. 空载不接电机，测量四路输出引脚静态电位，确认芯片硬件无损坏自锁；
3. 烧录简易PWM测试固件，单独输出驱动信号，准备接入电机负载。
以下测量结果是空载时线性稳压器的稳定电压5V：
![电机启动稳压器电压](./Schematic%20diagram%20and%20PCB/VIN%20AND%20VOUT.jpg)

#### 3.3 驱动芯片焊接故障排查（首次整机故障）
1. 单路电机接入排母，滑动电机插头切换不同接触位置测试电机运转状态；
2. 故障现象：仅右下角排针位置电机可正常转动，其余点位无任何动作，更换电机后现象不变；
3. 根因定位：RZ7899贴片底部焊盘大面积虚焊，驱动输出供电不稳定；
4. 修复操作：在备用练习板熟悉贴片拖焊工艺，原PCB底面重新补锡加固RZ7899全部引脚；
5. 修复验证：四路电机独立接入均可实现正转、反转、无级调速，单芯片驱动故障解决。

#### 3.4 电机触点接触稳定性整机调试（装配后负载故障）
1. 四路电机全部装配固定，烧录完整机器人整机固件，同步启动电机测试；
2. 故障现象：左下角电机间歇性断电停转，其余三路长时间运行稳定；
3. 分层排查过程：
   ① 重新焊接PCB电机输出焊盘，故障无改善；
   ② 互换电机、更换全新排针，排除PCB线路与驱动芯片问题；
   ③ 锁定根因：电机金属触点狭小，装配挤压后接触面变形，震动下极易断开；
4. 临时解决方案：调整电机安装角度，使电机金属尖端顶住排母弹片，机械固定座锁死姿态，维持稳定接触；
5. 可靠性验证：电机连续启停、长时间空载运行，无断连停机现象，功能恢复正常。

#### 3.5 辅助性能补充调试
1. 电源干扰测试：电机全速运转时通过ADC采集系统电压，验证PCB隔离走线、铺铜接地方案可有效抑制大功率负载干扰；
2. 低压工况测试：电池电压下降过程中观测电机动力变化，记录驱动电路最低稳定工作电压；
3. 固件参数匹配：调试PWM输出参数，将最优转速区间写入BSP硬件参数宏，固化至固件架构。

### 4. 本次调试故障汇总与根因分析
| 故障现象 | 根本原因 | 临时解决办法 | 长期优化方案 |
|--------|--------|------------|------------|
| 单路电机仅特定排针点位运转 | RZ7899贴片虚焊 | 底部拖焊补锡加固芯片引脚 | 后续改版PCB增大贴片焊盘、增加阻焊开窗 |
| 左下角电机震动后间歇停机 | 电机金属触点接触面变形过小 | 调整电机角度，尖端顶住排母弹片机械固定 | 新版结构更换带焊片电机、取消直插触点结构 |
| 电机启停时ADC电压小幅波动 | 大功率走线未充分隔离 | 固件ADC增加均值滤波算法 | PCB改版加宽驱动地线，电机区域独立铺铜 |

### 5. 调试收获与软硬件设计优化建议
#### 硬件PCB层面
1. 贴片驱动芯片（RZ7899）焊盘预留充足焊接余量，缩小虚焊概率；
2. 大功率电机走线严格遵循≥35mil线宽，ADC模拟信号线与驱动电源线完全分离，减少电磁干扰；
3. 电机外接接口优先预留焊接焊盘，尽量避免仅依靠细小金属触点直插接触；
4. 铺铜增加线性排布缝合孔，消除孤岛铜，稳定全局GND电位。

#### 元器件选型层面
1. 无标准封装器件（STC32主控、电池座、电机）采购前完整核对尺寸、引脚、接触结构，避免选型失误带来跳线、接触不良问题；
2. 电机优先选用带加长金属焊片型号，提升装配后接触可靠性。

#### 固件架构层面
1. HAL层独立封装RZ7899驱动接口，支持单路电机单独开关、调速，方便分路调试定位故障；
2. App层增加硬件自检逻辑，上电后依次驱动四路电机，串口打印每一路工作状态，快速识别驱动异常；
3. ADC采样增加滑动均值滤波，抵消电机启停带来的电源噪声，提升电压检测精度。

### 6. 遗留待优化项
1. 硬件：RZ7899焊盘需要改版放大；电机接口增加焊接焊盘，取消单纯金属触点直插；
2. 固件：ADC增加滑动均值滤波抵消电机启动电压扰动；
3. 当前无电机电流检测电路，无法检测堵转故障。
