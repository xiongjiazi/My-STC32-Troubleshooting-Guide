## 项目概述

该项目主要用于学习和实践嵌入式硬件系统开发流程，涵盖主控系统、电机驱动、传感器采集以及外围功能电路设计。项目开发过程中重点关注硬件系统的稳定性、模块之间的协同工作以及实际调试过程中的问题分析。
项目的电路原理图绘制、PCB绘制以及成品打样均在嘉立创EDA完成。

在项目开发过程中，主要围绕以下工程内容展开：

- 电源供电电路设计与功能验证；
- MCU 外围电路设计与模块集成；
- 电机驱动电路调试与运行测试；
- 传感器信号采集与功能验证；
- 硬件异常问题定位与优化。

ps：该项目基于嘉立创EDA环境完成，包含的原理图以及PCB文件均可在嘉立创EDA中打开查看。

## 1. 主控模块

本项目主控选用 STC32G12K128，该系列为 32 位架构 8051 内核单片机，主打高抗干扰、低成本、高速运行与低功耗特性。
芯片集成高精度内部 R/C 时钟，无需外置晶振即可工作，系统主频可达 33MHz。片内外设资源充足，搭载 4 路串口、
5 组通用定时器、2 组带死区保护的高级 PWM 定时器，同时引出 IIC、SPI、USB、CAN、LIN 通信接口，
配套 12 位高速 ADC 与模拟比较器，硬件资源可完整覆盖本机器人全部控制、采集与驱动设计需求。
MCU主要负责包含配合外部传感器完成信号采集，利用PWM 信号输出完成电机控制，
进行ADC 数据采集完成实时数据可视化，配合外围设备控制。

### 电源电路设计过程及计算过程
本项目电源输入部分采用的是防反接+开关控制+7805线性稳压的方案，为MCU及外围控制电路提供稳定的+5V电源。
设计的适合考虑到电源首先接二极管起到反接保护；7805线性稳压器出入口接滤波电容降低电源波动。使用L7805稳定输出电压稳定在+5V，
满足电机的额定电压需求；通过红LED指示电源工作状态；预留ADC电压检测，用于运行过程当中检测系统供电状态以及调试过程具有可视化数据。

#### 关键参数计算
**1. 线性稳压功耗**

L7805 的功耗主要由输入输出压差产生：

$P_D=(V_{IN}-V_{OUT})\times I_{OUT}$

根据实际输入电压和负载电流估算稳压器功耗，并据此判断温升及散热需求。

**2. 电源负载估算**

系统总负载电流可按照 MCU、传感器、LED、蜂鸣器及其他外围模块分别估算：

$I_{TOTAL}=\sum I_n$

实际电源设计预留一定电流裕量，避免长期接近稳压器额定输出能力运行。

**3. 防反接二极管功耗**

根据二极管正向压降和工作电流估算损耗：

$P_D=V_F\times I$

用于校核二极管的电流及功耗是否满足实际工作需求。

**4. LED限流电阻**

LED 指示电路按照目标工作电流选择限流电阻：

$R=\frac{V_{CC}-V_F}{I_F}$

根据计算结果选择接近的标准阻值，并结合实际亮度进行验证。

### 热设计与设计约束
当前配置15.5×10.5×24mm H型散热片；该散热方案余量有限，长时间大负载工况下温升风险较高，改版可增大散热面积、加强铺铜导热。

## 5. ADC 电压检测模块

为了方便观察实时系统运行状态，因此设计 ADC 电压采集电路，通过 MCU ADC 功能读取系统电压信息，
并通过串口输出至电脑端或进行更新外接一个小显示器进行显示。该模块用于后期调试对比电压情况，
分析实际情况遇到的问题的根本原因，排除问题的其他可能，缩小锁定问题的范围。

### 电路设计

电路由 R3、R4 和 R6 构成电阻分压网络：

- R3 = 10 kΩ
- R4 = 10 kΩ
- R6 = 10 kΩ

其中 R3 与 R4 串联构成分压电路上臂：

$\[
R_1=R3+R4=20k\Omega
\]$

R6 构成下臂：

$\[
R_2=10k\Omega
\]$

ADC 采样点连接在 R4 与 R6 之间。

![ADC电压检测电路原理图](./Schematic%20diagram%20and%20PCB/ADC%20power%20supply%20detection%20circuit.png)

### 分压计算

根据电阻分压公式：

$\[
V_{ADC}=V_{IN}\times\frac{R_2}{R_1+R_2}
\]$

代入实际电阻参数：

$\[
V_{ADC}=V_{IN}\times\frac{10k}{20k+10k}
\]$

因此：

$\[
V_{ADC}=\frac{V_{IN}}{3}
\]$

反推实际输入电压：

$\[
V_{IN}=3\times V_{ADC}
\]$

即 MCU ADC 检测到的电压为实际输入电压的 1/3。

### ADC 数值换算

假设 ADC 分辨率为 \(N\) 位，ADC 满量程参考电压为 \(V_{REF}\)，ADC 原始采样值为 \(ADC_{Value}\)，则 ADC 引脚实际电压为：

$\[
V_{ADC}=
\frac{ADC_{Value}}{2^N-1}
\times V_{REF}
\]$

结合本电路 1/3 的分压关系，系统实际输入电压为：

$\[
V_{IN}=3\times
\frac{ADC_{Value}}{2^N-1}
\times V_{REF}
\]$

程序通过上述关系将 ADC 原始采样值换算为实际电源电压，并通过 UART 输出至电脑端进行观察。

### 设计考虑

采用电阻分压方式进行电压检测，可以在不直接将系统输入电压接入 MCU ADC 引脚的情况下完成供电状态监测。

实际调试中，可通过万用表测量输入电压，并与 UART 输出的 ADC 换算结果进行对比，验证电压检测电路及软件换算结果。

为了ADC电压检测模块数值精确，建议电源类走线尽可能避开ADC检测用线。

### 1. 电源设计

由于系统同时包含 MCU 控制部分、电机驱动部分以及多个传感器模块，电源部分需要兼顾稳定供电和负载变化带来的影响。

设计过程中主要考虑：

- 区分电源线实际符合要求的口径大小；
- 区分控制电路与驱动电路供电路径；
- 合理规划电源走线；
- 增加必要的滤波与去耦措施；
- 为后续系统调试提供电压检测接口。


### 2. 元件布局规划

PCB布局根据不同功能模块进行区域划分：

- MCU最小系统区域；
- 电机驱动区域；
- 电源管理区域；
- 传感器接口区域；
- 外围功能电路区域。

通过模块化布局，提高电路可读性，同时方便后期硬件调试和故障定位。

### 3. 后续优化方向

当前版本 PCB 主要完成基础功能验证，后续版本将根据实际运行情况进一步优化：

- 电源抗干扰设计；
- 信号完整性优化；
- 接口保护设计；
- PCB布局细节优化；
- 蓝牙驱动控制设计。


## 软件架构

本项目以 STC32G12K128 为控制核心。随着 LED、蜂鸣器、电机驱动、红外传感器和电压检测等功能逐步加入，程序也按照不同的硬件功能进行了划分，避免将所有控制逻辑集中在同一部分代码中。

目前固件主要围绕 GPIO、PWM、ADC 和 UART 等片上资源展开。程序运行过程中，控制部分负责根据需要输出相应信号，采集部分读取外围电路状态，部分调试信息则通过串口发送至电脑端，用于观察系统运行情况和辅助硬件调试。


### MCU资源分配

| MCU资源 | 功能 |
| ---- | ---- |
| GPIO | LED、蜂鸣器、传感器控制 |
| PWM | 电机速度控制 |
| ADC | 系统电压采集 |
| UART1 | 调试信息输出 |

### 程序功能划分

#### 电机控制

电机部分通过 PWM 信号与驱动电路配合工作。在调试阶段，首先对 PWM 输出进行验证，再观察驱动电路和电机的实际响应情况。

目前已完成基本的 PWM 调速测试，能够根据不同的占空比观察电机运行状态，为后续控制逻辑的进一步完善提供基础。

#### 电压采集与数据输出

系统通过 ADC 对电源电压进行采样。由于 ADC 读取的是经过分压后的电压信号，程序中需要根据电阻分压关系对采样结果进行换算，得到对应的系统输入电压。

换算后的数据通过 UART1 输出到电脑端，可以直接观察当前电压变化。这个功能主要用于验证电压检测电路，同时也为调试过程中观察系统供电状态提供参考。

#### 外设控制

LED 和蜂鸣器等简单外设主要通过 GPIO 进行控制，用于完成基本的状态指示和报警功能。

红外模块同样通过 GPIO 获取状态信号，并根据传感器输出参与循迹功能。目前相关功能已经完成基础验证。

### 当前状态

目前程序已经完成与现有硬件的基本配合，包括电机 PWM 控制、ADC 电压采集、串口数据显示、LED 与蜂鸣器控制以及红外循迹等功能。

现阶段的软件仍以硬件功能验证和基础控制为主，部分功能还处于持续测试阶段。超声波模块已经预留相关硬件接口，但避障功能尚未完成实际验证；下一版本计划加入蓝牙通信，通过移动端进一步扩展小车的控制方式。

随着后续硬件功能增加，程序也将继续根据实际调试情况进行调整和完善。


## 调试案例：RZ7899电机驱动电路调试
### 1. 模块基础信息
- 驱动芯片：RZ7899 贴片封装
- 执行器件：四路N20 5V减速电机，减速比1:240
- 主控：STC32G12K128，通过定时器PWM输出控制驱动
- PCB硬件版本：53*23mm主控底板
- 供电方案：7.4V锂电 → L7805CV稳压5V为驱动与MCU供电
- 硬件连接方式：PCB焊盘引出排母拓展接口，电机金属触点直插排母

### 2. 调试前置条件
1. PCB完成焊接，万用表预检无短路；
2. 底层固件完成GPIO、PWM驱动封装；
3. 测试工具：数字万用表、debug串口调试助手、电烙铁、固定支架；
4. PCB设计规范约束：驱动电源线宽40mil，ADC检测走线与电机功率线路物理隔离，全域铺铜+线性缝合孔完整接地。

### 3. 分步调试操作流程
#### 3.1 不通电预检
1. 目视检查RZ7899贴片所有引脚，排查少锡、连锡、偏移虚焊；
2. 万用表通断档测量驱动电源、四路电机输出引脚，确认无对地/对电源短路；
3. 核对排母与RZ7899输出引脚导通一致性，确认线路无断连。

#### 3.2 空载上电硬件电气测试
1. 接入锂电供电，测量L7805输出稳定5V，RZ7899供电引脚电压正常；（以下时测量图）
2. 空载不接电机，测量四路输出引脚静态电位，确认芯片硬件无损坏自锁；
3. 烧录简易PWM测试固件，单独输出驱动信号，准备接入电机负载。

#### 3.3 电机驱动与连接故障排查

##### 问题背景

在完成电机驱动电路焊接并进行整机调试后，对四路电机分别进行正反转及 PWM 调速测试。调试过程中先后出现多路电机无响应和单路电机间歇性停转等问题。

##### 故障现象

初步测试时，仅部分排针位置能够正常驱动电机，其余通道无明显响应。更换电机后故障现象保持不变。

在修复驱动电路并完成整机装配后，左下角电机又出现间歇性停转，而其余三路电机运行正常。

##### 排查过程

按照“电机负载 → 接触连接 → PCB线路 → 驱动芯片”的顺序进行检查：

1. 通过单路电机切换不同接口位置进行测试，确认故障并非由单个电机损坏引起；
2. 检查 PCB 电机输出及相关焊点，结合不同位置的测试结果排查线路问题；
3. 对驱动芯片焊接状态进行检查，发现 RZ7899 底部焊盘存在虚焊，导致部分驱动输出异常；
4. 修复芯片焊接后，四路电机均可正常实现正转、反转及 PWM 调速；
5. 整机装配后针对单路间歇性停转问题，进一步互换电机并检查连接方式，最终定位为装配空间挤压导致电机金属触点接触不稳定。

##### 修复与验证

针对 RZ7899 虚焊问题，对芯片引脚及底部焊接位置重新补锡加固；针对电机触点接触不良问题，调整电机安装位置，使金属触点与排母保持稳定接触，并通过固定结构减少运行过程中的松动。

修复后对四路电机进行独立及整机测试，完成正反转、PWM 调速、连续启停和长时间空载运行验证，未再出现异常停转现象。

### 4. 本次调试故障汇总与根因分析
| 故障现象 | 根本原因 | 临时解决办法 | 长期优化方案 |
|--------|--------|------------|------------|
| 单路电机仅特定排针点位运转 | RZ7899贴片虚焊 | 底部拖焊补锡加固芯片引脚 | 后续改版PCB增大贴片焊盘、增加阻焊开窗 |
| 左下角电机震动后间歇停机 | 电机金属触点接触面变形过小 | 调整电机角度，尖端顶住排母弹片机械固定 | 新版结构更换带焊片电机、取消直插触点结构 |
| 电机启停时ADC电压小幅波动 | 大功率走线未充分隔离 | 固件ADC增加均值滤波算法 | PCB改版加宽驱动地线，电机区域独立铺铜 |

### 5. 调试收获与软硬件设计优化建议
#### 硬件PCB层面
1. 贴片驱动芯片（RZ7899）焊盘预留充足焊接余量，缩小虚焊概率；
2. 大功率电机走线严格遵循≥35mil线宽，ADC模拟信号线与驱动电源线完全分离，减少电磁干扰；
3. 电机外接接口优先预留焊接焊盘，尽量避免仅依靠细小金属触点直插接触；
4. 铺铜增加线性排布缝合孔，消除孤岛铜，稳定全局GND电位。

#### 元器件选型层面
1. 无标准封装器件（STC32主控、电池座、电机）采购前完整核对尺寸、引脚、接触结构，避免选型失误带来跳线、接触不良问题；
2. 电机优先选用带加长金属焊片型号，提升装配后接触可靠性。

#### 固件架构层面
1. HAL层独立封装RZ7899驱动接口，支持单路电机单独开关、调速，方便分路调试定位故障；
2. App层增加硬件自检逻辑，上电后依次驱动四路电机，串口打印每一路工作状态，快速识别驱动异常；
3. ADC采样增加滑动均值滤波，抵消电机启停带来的电源噪声，提升电压检测精度。

### 6. 可优化项
1. 硬件：RZ7899焊盘需要改版放大；电机接口增加焊接焊盘，取消单纯金属触点直插；
2. 固件：ADC增加滑动均值滤波抵消电机启动电压扰动；
3. 当前无电机电流检测电路，无法检测堵转故障。
