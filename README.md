## 项目概述

本项目是一套基于 **STC32G12K128 微控制器**开发的工厂货运机器人原型机。

该项目主要用于学习和实践嵌入式硬件系统开发流程，涵盖主控系统、电机驱动、传感器采集以及外围功能电路设计。项目开发过程中重点关注硬件系统的稳定性、模块之间的协同工作以及实际调试过程中的问题分析。
项目的电路原理图绘制、PCB绘制以及成品打样均在嘉立创EDA完成。嘉立创EDA导出的eprj文件`工厂货运机器人原型机_第一版.eprj2`包含有电路原理图以及PCB设计。

当前版本集成的主要功能模块包括：

- **STC32G12K128 主控系统**
- **四路电机驱动系统**
- **红外循迹检测模块**
- **超声波距离检测模块**
- **蜂鸣器状态提示电路**
- **白色 LED 照明电路**
- **ADC 电压检测电路**


在项目开发过程中，主要围绕以下工程内容展开：

- 电源供电电路设计与功能验证；
- MCU 外围电路设计与模块集成；
- 电机驱动电路调试与运行测试；
- 传感器信号采集与功能验证；
- 硬件异常问题定位与优化。


本仓库记录该移动机器人平台从硬件设计、模块调试到功能验证过程中的相关内容，包括：

- 电路设计思路；
- 元器件选型记录；
- PCB 设计注意事项；
- 硬件调试过程；
- 问题分析与解决方案；
- 后续版本功能扩展规划。


## 项目特色

### 嵌入式控制平台

- 基于 STC32G12K128 微控制器；
- 集成多种外围功能模块；
- 为后续功能扩展提供硬件基础。

### 多功能硬件集成

系统集成：

- 电机驱动电路；
- 传感器接口；
- 电源供电电路；
- ADC 电压检测电路；
- 蜂鸣器及 LED 外围功能电路。


### 硬件调试与功能验证

开发过程中重点关注硬件系统稳定性以及实际运行中的问题定位。

目前已完成：

- 电源电路功能验证；
- 电机驱动测试；
- PWM 调速实验；
- ADC 电压采集测试；
- 外围模块联调。


针对部分尚未完成的功能，例如超声波避障模块，
后续将通过实际测试验证传感器兼容性、
信号稳定性以及控制算法实现。
